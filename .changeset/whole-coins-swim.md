Major runtime and DX polish across the Lithia framework.

This release refines Lithia's worker-based architecture, async task runtime, OpenAPI support, startup lifecycle, examples, templates, and package metadata. The core runtime was reorganized and hardened, async tasks replaced the old managed functions model, OpenAPI + Scalar integration was added, `app/server.ts` bootstrap support was introduced, and the public API/docs/readme surface were updated to better match the current framework direction.
