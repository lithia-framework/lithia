## Overview

`@lithia-js/utils` contains shared utilities used internally by Lithia
packages. It is not the main entrypoint for building a Lithia app.

Typical responsibilities include:

- logger helpers used by the CLI and runtime
- terminal formatting helpers
- shared utility types consumed by other Lithia packages
